# Mutabaah Tahfidz Nurista
Aplikasi web pencatatan capaian tahfidz santri Pesantren Nurul Islam Tengaran
(Next.js 15 · Netlify Database · cadangan otomatis ke Google Spreadsheet via Apps Script).

Lihat **PANDUAN-DEPLOY.md** untuk cara memasang di Netlify.

Variabel lingkungan yang wajib diisi di Netlify: `GAS_URL`, `SYNC_KEY`.
